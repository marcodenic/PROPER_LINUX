## Output and review convention

- Build inputs remain in Git; ISO images, VM disks, caches, and logs go in a directory outside Git (the scripts default to ../proper-linux-build).
- scripts/run-vm exposes the graphical VM through a local QEMU window. Capture PM evidence with the host screenshot tool or the VM display capture facility once QEMU/KVM is available.

## Current blockers

The environment-check command records availability rather than installing packages. A build requires KIWI, QEMU, OVMF, xorriso, an enabled container/runtime path if used, and privileged image-build access. Graphical acceptance additionally requires readable and writable /dev/kvm.
