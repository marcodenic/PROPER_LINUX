# Proper Linux shortcuts

Search this page from Vicinae: it is the pointer-friendly reference for the
shortcuts shipped by Proper Linux.

| Shortcut | Action |
| --- | --- |
| Meta+Space | Open Vicinae |
| Alt+F2 | Open KRunner fallback |
| Meta+Left / Right | Quick-tile window to half |
| Meta+Up / Down | Maximise or restore a window |
| Meta+H | Minimise the active window |
| Meta+E | Open Files (Dolphin) |
| Meta+Enter | Open Ghostty terminal |
| Meta+Shift+S | Capture a selected screen region |

All actions remain available through the taskbar, application menus, window
buttons, and ordinary pointer interaction.
